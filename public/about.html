MoMA Art Collection

About This App

Description: This application provides a search interface for the MoMA Art Collection. It supports all CRUD operations on artworks and includes pagination, and search/filtering.

How It Works: On startup, the server loads the complete Artworks.json into an in-memory MongoDB instance. The REST API uses endpoints for listing, creating, updating, deleting, and searching artworks.

Technologies:

  • Backend: Node.js, Express.js, mongodb-memory-server
  • Frontend: HTML5, Bootstrap 5

Known Weaknesses:

  • When the database is restarted it is not persistent and needs to be created on every startup.
  • No authenication or role based control.

Alternative Approaches & Enhancements:

  • Persist data by using a cloud based database hosting platform.
  • use some type of API authenication method like JWT.
  • Use React to build the frontend.
